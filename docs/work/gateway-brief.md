## Shared contracts
Config: models: dict[str,ModelConfig], model fields name,reasoning_effort,verbosity,input_usd_per_million/output_usd_per_million (nullable); config.limits.max_model_attempts,max_pdf_mb,max_model_runs,max_output_tokens,max_context_chars,daily_budget_usd; config.runtime.timeout_seconds,retry_base_seconds,lease_seconds; config.tracing.enabled; config.literature.download_open_access_pdfs. Config comes from config.py (another worker).

Database db.py: db.execute(sql:str,params:tuple=())->int (lastrowid); db.query(sql,params=())->list[dict]; db.one(sql,params=())->dict|None; db.transaction() is sync context manager yielding sqlite3.Connection with Row factory. db.project returns dict(id=1,slug,...). No await inside transactions.
Paths paths.py: Paths(root:Path), .root Path, .resolve(relative:str)->Path enforces containment and no traversal; .read(relative:str)->str; .atomic_write(relative:str,content:str|bytes)->Path; .write_immutable(relative:str,content:str|bytes)->Path (raises on overwrite). resolve creates no directories; writes create parents.

ModelRuns schema root creates:
id TEXT PRIMARY KEY, project_id INTEGER DEFAULT 1, agent_role TEXT, scope_type TEXT, scope_id TEXT, action_key TEXT, model_name TEXT, reasoning_effort TEXT, prompt_hash TEXT, prompt_path TEXT, started_at TEXT DEFAULT utc timestamp, completed_at TEXT, input_tokens INTEGER, output_tokens INTEGER,total_tokens INTEGER,estimated_cost_usd REAL, reserved_cost_usd REAL DEFAULT 0,trace_id TEXT,status TEXT,error TEXT,raw_output_path TEXT,metadata_json TEXT.
Unique successful logical action: unique index action_key where status='COMPLETED'. A completed run contains immutable typed response JSON in raw_output_path. Gateway should reuse a completed result for action key on recovery. Editor invocation is also cached; no recursive editing.
